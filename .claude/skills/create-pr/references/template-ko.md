# PR Template (ko)

한국 프로젝트, 한국어 기반 저장소용 `create-pr` 본문 템플릿. 대괄호(`[...]`)로 된 안내 문구는 실제 내용으로 교체하고, 해당 사항이 없는 섹션은 삭제하지 말고 `해당 없음`으로 둔다.

```markdown
## 요약

[1~3문장: 이 PR이 무엇을 하는지, 왜 필요한지.]

## 변경 사항

- [핵심 변경 1]
- [핵심 변경 2]

## 배경 / 맥락

[변경이 필요한 이유. 관련 이슈 연결: Closes #123]

## 테스트 방법

- [ ] [실제로 실행한 명령어나 절차. 예: `bun run test`]
- [ ] [수동 확인 절차가 있다면 기재]

## 스크린샷

[UI 변경 시 변경 전/후. 없으면 해당 없음.]

## 호환성 영향 (Breaking Changes)

[호환성을 깨는 변경과 마이그레이션 방법. 없으면 해당 없음.]

## 체크리스트

- [ ] 테스트 추가 또는 수정
- [ ] 린트와 빌드 통과
- [ ] 문서 갱신 (필요한 경우)
```
