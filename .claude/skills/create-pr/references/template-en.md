# PR Template (en)

해외 오픈소스 프로젝트, 영어 기반 저장소용 `create-pr` 본문 템플릿. 대괄호(`[...]`)로 된 안내 문구는 실제 내용으로 교체하고, 해당 사항이 없는 섹션은 삭제하지 말고 `N/A`로 둔다.

```markdown
## Summary

[1-3 sentences: what this PR does and why.]

## Changes

- [Key change 1]
- [Key change 2]

## Motivation / Context

[Why this change is needed. Link related issues: Closes #123]

## How to Test

- [ ] [Command or steps you actually ran, e.g. `bun run test`]
- [ ] [Manual verification steps, if any]

## Screenshots

[Before / after for UI changes. N/A otherwise.]

## Breaking Changes

[Describe any breaking changes and the migration path. N/A if none.]

## Checklist

- [ ] Tests added or updated
- [ ] Lint and build pass
- [ ] Documentation updated (if needed)
```
